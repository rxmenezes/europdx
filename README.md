# europdx
Here you can find code to analyse data for the European Project on Patient-derived Xenographs
Code for generating dynamic reports for analysis of CRC models are included. The correspondence between the files and the CRC models in the manuscript is as follows:

> CUP0002 -> CRC1331

> CUP0003 -> CRC1272

> CUP0005 -> CRC1502

> CUP0006 -> CRC0030

> CUP0008 -> CRC0148

> CUP0009 -> CRC0065

The code for a dynamic report for breast cancer models, not mentioned in the referred publication, is also included.
